# 🎓 GTU Academic Calculator

A simple and useful web-based academic calculator for GTU Diploma and Engineering students. This project helps students calculate CIA average, grade, and percentage from CGPA using an easy-to-use interface.

---

## 🚀 Features

✅ CIA Calculator

✅ Grade Calculator

✅ CGPA to Percentage Converter

✅ Dark Mode Support

✅ Mobile Responsive Design

✅ Simple & Clean UI

✅ Instant Result Calculation

✅ Beginner Friendly Project
